# Sawera — Portfolio

Personal portfolio website for Sawera — CS student, freelance web developer and founder — built with React, TypeScript and Three.js, featuring an interactive 3D yarn ball and a live crochet-pattern demo.

**Live:** https://sawera-portfolio.vercel.app

## Tech stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Three.js with @react-three/fiber and @react-three/drei
- framer-motion + Lenis
- lucide-react + react-icons

## Run locally

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```

## Content

All portfolio text and data (about, skills, experience, projects, education, socials) lives in [`src/data/content.ts`](src/data/content.ts) — edit that file to update the site.
